# Jordan Covenant Matovu — Cybersecurity Portfolio

A responsive, light-theme static portfolio designed for GitHub Pages and tailored to entry-level SOC Analyst, Junior Cybersecurity Analyst, and Security Automation opportunities.

## Files

- `index.html` — page content and project sections
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation and current year

## Before publishing

1. Review all content for accuracy.
2. Replace the LinkedIn and GitHub placeholder links in `index.html` with your actual profile URLs.
3. Add a link to your resume PDF only if you want to make it public.
4. Update project statuses only after the work has actually been implemented and tested.
5. Add real project screenshots, architecture diagrams, and sanitized sample outputs as they become available.
6. Never publish employer data, internal logs, credentials, tokens, private IP details, or other confidential information.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `your-github-username.github.io` (replace the example with your username).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The address will be `https://your-github-username.github.io/`.
7. Test the site on desktop and mobile, and verify that all links work.

If you prefer a repository with a different name, enable Pages in Settings and use the URL GitHub provides for that project site.

## Suggested project documentation structure

As projects are implemented, create a folder for each one, for example:

```text
projects/
  blue-team-threat-detection/
    README.md
    architecture.png
    detections/
    scripts/
    sample-data/
    reports/
```

Use synthetic or sanitized sample data. Clearly label unimplemented ideas as **Planned** and active work as **In progress**. Only claim results that you have personally reproduced and verified.

## Accessibility and design

The site includes semantic page sections, a skip link, responsive navigation, reduced-motion support, and a mobile layout. Review contrast, keyboard navigation, and all links before sharing with recruiters.
